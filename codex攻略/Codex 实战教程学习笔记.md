

## 01. 安装

学习如何准备电脑开发环境，完成 Codex 的安装与基础配置，为后续开发和自动化操作打好基础。

## 02. 基础使用

掌握 Codex 的日常使用方式，包括同时处理多个任务、管理项目、控制权限，以及维护上下文信息。

## 03. 画图

学习如何通过明确的引导指令，让 Codex 辅助生成图表、流程图或结构化视觉内容。

## 04. 计划模式

使用计划模式拆解复杂任务，让 Codex 先规划步骤，再逐步执行，适合调试、修改和批注类工作。

## 05. 代码管理

学习结合 Git 管理代码版本，包括分支操作、代码回滚，以及使用 Git WorkTree 处理多个开发任务。

## 06. 云端模式

了解如何在云端运行 Codex，适合远程开发、后台执行任务和跨设备继续工作。

## 07. 记忆系统

通过 Agents.md 等配置文件，让 Codex 记住项目规则、开发偏好和行为约束，提高长期协作效率。

## 08. 插件与自动化

学习连接 GitHub、Gmail 等插件，并结合定时任务实现自动化工作流，减少重复操作。

## 09. Skills

了解 Skills 的作用，包括使用官方技能、社区技能，以及创建自定义技能来扩展 Codex 能力。

## 10. MCP

学习通过 MCP 连接外部工具和服务，例如 Supabase，让 Codex 可以操作数据库或调用更多开发资源。

## 11. 项目部署

掌握将项目部署到 Netlify 等平台的流程，让本地开发成果可以快速上线并对外访问。

## 12. 电脑自动化

学习使用 Computer Use 让 Codex 操作电脑界面，完成跨软件、跨网页的自动化任务。
