## 连接 PX4 和 Gazebo

先打开一个终端启动 PX4：

```
cd ~/PX4-Autopilot
make px4_sitl gz_x500
```

保持 PX4 终端和 Gazebo 窗口运行。

再新建一个终端启动 QGC：

```
cd ~/Desktop
./QGroundControl.AppImage
```

正常情况下 QGC 会自动连接本机运行的 PX4 SITL。连接成功后：

- QGC 顶部出现飞行器状态；
- 地图或飞行页面出现无人机；
- PX4 中的这条警告会消失：

```
Preflight Fail: No connection to the ground control station
```

然后在 PX4 的 `pxh>` 后检查：

```
commander check
```

健康检查通过后起飞：

```
commander takeoff
```

降落：

```
commander land
```
