一、核心统测大纲（按分值权重分块）

根据统测要求，试卷总分 100 分，考试时间 120 分钟，闭卷笔试。

### 模块一：数字逻辑概论（分值占比：10%）

- **核心考点**：
    - **数字信号与模拟信号的特征与区别**：
        - **模拟信号**：在时间和数值上均为**连续变化**的信号。
        - **数字信号**：在时间和数值上均为**离散**的信号。
        - **核心区别**：连续性、精度、抗干扰、存储与处理、典型应用。
    - **数制转换**：二进制（B）、八进制（O）、十进制（D）、十六进制（H）之间的相互转换（**必考点**）：
        **① 任意进制 → 十进制（按权展开法）**：$(N)_R = \sum_{i=-m}^{n-1} K_i \cdot R^i$
        **② 十进制 → 任意进制**：整数部分除 $R$ 取余逆序；小数部分乘 $R$ 取整顺序。
        **③ 二进制 ↔ 八进制（3 位一组）**
        **④ 二进制 ↔ 十六进制（4 位一组）**
        **⑤ 八进制 ↔ 十六进制**：以二进制为桥梁。
    - **二进制运算**：算术运算（加法、乘法）：
        **① 二进制加法**：逢 2 进 1。
        **② 二进制减法**：转化为补码加法。$A - B = A + (-B)_{\text{补}}$。
        **③ 二进制乘法**：逐位相乘后移位相加。
        **④ 二进制除法**：通过比较和减法实现。
    - **二进制编码**：熟练掌握 **8421BCD 码**的编码规则及运算：
        **定义**：用 4 位二进制数表示 1 位十进制数（0~9）。
        **非法码**：1010~1111 不合法。
        **8421BCD 加法运算**：结果 > 9 或产生进位时需 **+6 (0110) 修正**。
        其他常见 BCD 码：余 3 码、2421 码、5421 码。

### 模块二：逻辑代数基础（分值占比：20%）

- **核心考点**：
    - **基本运算**：与、或、非、与非、或非、异或、同或的逻辑符号及运算：
        | 运算 | 表达式 | 规则 |
        |:---:|:---:|:---|
        | 与 (AND) | $Y=AB$ | 全 1 出 1，有 0 出 0 |
        | 或 (OR) | $Y=A+B$ | 有 1 出 1，全 0 出 0 |
        | 非 (NOT) | $Y=\bar{A}$ | 取反 |
        | 与非 (NAND) | $Y=\overline{AB}$ | 与后取反 |
        | 或非 (NOR) | $Y=\overline{A+B}$ | 或后取反 |
        | 异或 (XOR) | $Y=A\oplus B=\bar{A}B+A\bar{B}$ | 不同出 1 |
        | 同或 (XNOR) | $Y=A\odot B=AB+\bar{A}\bar{B}$ | 相同出 1（异或取反） |
    - **逻辑函数表示方法**：真值表、逻辑表达式、卡诺图、逻辑图的互相转换：
        1. **真值表**：$n$ 个变量有 $2^n$ 行。
        2. **逻辑表达式**：与-或式（SOP）、或-与式（POS）、最小项表达式。
        3. **卡诺图**：按格雷码排列，相邻方格只有一个变量取反。
        4. **逻辑图**：逻辑门符号电路图。
    - **基本定律与规则**：
        **三大规则**：
        1. **代入规则**：变量用逻辑函数代入，等式仍成立。
        2. **反演规则（常考）**：求反函数——$\cdot \leftrightarrow +$，$0 \leftrightarrow 1$，原变量 $\leftrightarrow$ 反变量，运算顺序不变。
        3. **对偶规则**：$\cdot \leftrightarrow +$，$0 \leftrightarrow 1$，但**变量不变**。
        **常用公式**：
        - **摩根定律**：$\overline{A+B}=\bar{A}\cdot\bar{B}$，$\overline{A\cdot B}=\bar{A}+\bar{B}$
        - **吸收律**：$A+AB=A$；$A+\bar{A}B=A+B$；$AB+\bar{A}C+BC=AB+\bar{A}C$
        - **基本恒等式**：$A+0=A$、$A+1=1$、$A\cdot 0=0$、$A\cdot 1=A$、$A+\bar{A}=1$、$A\cdot \bar{A}=0$
    - **逻辑函数化简（重难点）**：
        1. **代数化简法**：利用公式化简。
            **常用手法**：并项法、吸收法、消去法、配项法。
        2. **卡诺图化简法**：含**约束项**的卡诺图化简（**大题必考**）。
            **步骤**：①填图 → ②圈 $2^n$ 个相邻 1 → ③写与项 → ④相加。
            **约束项（无关项）**：记作 $\times$，可作 1 圈也可作 0 不圈。
            **注意事项**：不遗漏 1、圈 $2^n$ 格、边界相邻（循环）。

### 模块三：组合逻辑电路（分值占比：30%）

- **核心考点**：
    - **经典分析与设计**：
        - **分析**：逻辑图 $\rightarrow$ 表达式 $\rightarrow$ 化简 $\rightarrow$ 真值表 $\rightarrow$ 判断逻辑功能。
        - **设计**：实际问题 $\rightarrow$ 真值表 $\rightarrow$ 表达式 $\rightarrow$ 化简/变换 $\rightarrow$ 逻辑门电路图。
    - **MSI 常用组合器件**：
        - **加法器**：74LS283（4 位二进制全加器）。$S=A+B+CI$，可级联扩展。
        - **编码器**：74LS148（8-3 线优先编码器），$I_7$ 优先级最高。
        - **译码器（重点：74LS138）**：3-8 线译码器。
            - 3 位地址 $A_2A_1A_0$，8 路输出 $\overline{Y_0}\sim\overline{Y_7}$（低有效）。
            - 使能端：$G_1=1$、$\overline{G_{2A}}=\overline{G_{2B}}=0$ 时工作。
            - **核心用法**：输出 $\overline{Y_i}=m_i$（最小项的非），用与非门汇总实现任意组合逻辑。
        - **数据选择器（重点：74LS153）**：双 4 选 1。
            - 地址 $A_1A_0$ 从 $D_0\sim D_3$ 中选 1 路输出。
            - **降维设计**：将 $n$ 变量函数的 1 个变量分离到 $D_i$（0、1、变量、反变量），$n-1$ 变量接地址。
        - **数值比较器**：74LS85（4 位），输出 $A>B$、$A=B$、$A<B$。
        - **核心要求**：利用 MSI 器件实现复杂组合逻辑功能。
    - **竞争-冒险现象**：
        - **产生原因**：信号路径时延不同导致竞争，产生尖峰脉冲（毛刺）。
        - **判断方法**：代数法（检查 $A\cdot\bar{A}$ 或 $A+\bar{A}$）、卡诺图法（相邻圈相切）。
        - **消除方法**：① 接入滤波电容；② 引入选通脉冲；③ 增加冗余项（最常用）。

### 模块四：触发器（分值占比：10%）

- **核心考点**：
    - **SR 锁存器**：
        - 与非门 SR 锁存器：$\overline{S_D}$、$\overline{R_D}$ 低有效；$\overline{S_D}=\overline{R_D}=0$ 为**禁止态**。
        - 或非门 SR 锁存器：$S_D$、$R_D$ 高有效；$S_D=R_D=1$ 为禁止态。
    - **边沿触发器**：只在 $CP$ 特定边沿（上升沿 $\uparrow$ / 下降沿 $\downarrow$）采样，克服空翻。
    - **三大触发器**：
        | 触发器 | 特性方程 | 功能 |
        |:--|:--|:--|
        | D 触发器 | $Q^{n+1}=D$ | 输出跟随输入 |
        | JK 触发器 | $Q^{n+1}=J\bar{Q}^n+\bar{K}Q^n$ | J=K=0 保持；01 置 0；10 置 1；11 翻转 |
        | T 触发器 | $Q^{n+1}=T\oplus Q^n$ | T=0 保持；T=1 翻转 |
        - 典型芯片：74LS74（双 D，上升沿）、74LS76（双 JK，下降沿）。
        - T' 触发器：T 恒为 1，每 CP 翻转一次，基本计数单元。
    - **触发器转换**：
        | 转换 | 驱动方程 | 
        |:--|:--|
        | D → T | $D = T \oplus Q^n$ |
        | D → JK | $D = J\bar{Q}^n + \bar{K}Q^n$ |
        | JK → D | $J = D$，$K = \bar{D}$ |
        | JK → T | $J = K = T$ |
        **通用方法**：令目标特性方程 = 原特性方程，解出驱动方程。

### 模块五：时序逻辑电路（分值占比：30%）

- **核心考点**：
    - **同步时序电路的分析**：
        ① 写驱动方程 → ② 状态方程 → ③ 输出方程 → ④ 状态转移表 → ⑤ 状态转移图/时序波形 → ⑥ 描述逻辑功能 → ⑦ **检查自启动**。
    - **同步时序电路的设计**：
        ① 逻辑抽象，设定状态 → ② 状态化简（等价状态合并） → ③ 状态编码（$2^n \geq M$） → ④ 确定触发器类型和数量 → ⑤ 求驱动方程和输出方程 → ⑥ 画逻辑图 → ⑦ **检查自启动**。
    - **MSI 常用时序器件**：
        - **寄存器**：74LS373（透明锁存器）、74LS374（边沿触发）、移位寄存器 74LS194。
        - **计数器（重点：74LS160、74LS161）**：
            - **74LS160**：同步十进制加法计数器，0000~1001，异步清零、同步置数。
            - **74LS161**：同步 4 位二进制加法计数器，0000~1111，异步清零、同步置数。
            - 使能端 $EP$、$ET$：均为 1 时计数；$RCO = ET \cdot$ 计数满条件。
        - **N 进制计数器设计**（不超过两片级联）：
            **① 置零法（清零法）**：计到 $N$ → 译码 $\overline{CR}=0$ → 强制归零。有效状态 $0\sim N-1$（异步清零，$N$ 瞬态不计入）。
            **② 置数法（预置法）**：用 $RCO$ 或译码 $N-1$ 触发 $\overline{LD}=0$，同步置入预置数。
            **③ 两片级联**：低位 $RCO$ 接高位 $EP/ET$，整体模值 = 两片模值之积。
