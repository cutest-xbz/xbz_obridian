# 微机原理重点学习大纲

## 一、微型计算机基础

### 1. 微型计算机系统组成

![[微机原理/attachments/Pasted image 20260619110344.png|492]]
重点掌握：

微型计算机由硬件系统和软件系统组成。硬件主要包括：

CPU、存储器、输入输出接口、总线、外设。

需要理解：

CPU 负责运算和控制；存储器保存程序和数据；I/O 接口连接外设；总线负责信息传送。

### 2. 微机系统工作过程

重点理解：

微机执行程序的基本过程是：

取指令 → 分析指令 → 执行指令 → 修改程序计数器 → 继续下一条指令

要知道程序最终是由一条条机器指令顺序执行或跳转执行完成的。

### 3. 数制与编码

重点掌握：

二进制、十进制、十六进制之间的转换。

常考内容：

二进制转十进制  
十进制转二进制  
十六进制和二进制互转  
BCD 码  
ASCII 码

### 4. 数据表示方法

重点掌握：

无符号数和有符号数。

有符号数重点是：

#### 原码、反码、补码
硬件的加法器无法识别符号位的特殊含义

**原码**：最高位是符号位，`0` 表示正数，`1` 表示负数，其余位表示数值大小。  
例如 8 位表示：`+5 = 00000101`，`-5 = 10000101`。

**反码**：正数的反码等于原码；负数的反码是在原码基础上，符号位不变，其余位取反。  
例如：`-5` 原码为 `10000101`，反码为 `11111010`。

**补码**：正数的补码等于原码；负数的补码是在反码基础上加 `1`。  
例如：`-5` 反码为 `11111010`，补码为 `11111011`。

最重要的是**补码运算**。

补码的意义：
	
- 计算机中有符号整数通常用补码表示。
- 补码可以把减法转换成加法，统一加减运算规则。
- 补码只有一个 `0`，避免了原码和反码中 `+0`、`-0` 同时存在的问题。
- 硬件的加法器无法识别符号位的特殊含义

常考：

8 位补码表示范围：-128 ~ +127  
16 位补码表示范围：-32768 ~ +32767

补码加减法是重点。

## 二、8086/8088 微处理器

## 1. 8086/8088 的基本特点

重点掌握：

8086 是 16 位微处理器。  
8088 内部是 16 位，外部数据总线是 8 位。

8086 和 8088 的区别是常考点。

8086：

内部 16 位，外部数据总线 16 位。

8088：

内部 16 位，外部数据总线 8 位。

## 2. 8086/8088 内部结构

重点掌握：

8086/8088 CPU 由两大部分组成：

BIU：总线接口部件  
EU：执行部件

BIU 负责取指令、形成物理地址、访问存储器和 I/O。  
EU 负责译码和执行指令。

## 3. 寄存器结构

这是重点中的重点。

需要掌握的寄存器：

通用寄存器：

AX、BX、CX、DX

可分成高 8 位和低 8 位：

AH、AL  
BH、BL  
CH、CL  
DH、DL

指针和变址寄存器：

SP、BP、SI、DI

段寄存器：

CS、DS、SS、ES

控制寄存器：

IP、FLAGS

重点理解：

CS:IP 指向下一条要执行的指令。  
SS:SP 指向堆栈顶部。  
DS 通常指向数据段。  
ES 常用于附加数据段，尤其是字符串操作。

## 4. 存储器寻址

重点掌握：

8086 使用分段管理方式。

物理地址计算公式：

物理地址 = 段地址 × 16 + 偏移地址

也可以写成：

物理地址 = 段地址 × 10H + 偏移地址

常考例子：

CS = 2000H，IP = 0100H

物理地址 = 20000H + 0100H = 20100H

这个公式必须熟练。

## 5. 8086/8088 引脚和总线

重点掌握：

地址总线  
数据总线  
控制总线

常见信号：

ALE：地址锁存允许  
RD：读信号  
WR：写信号  
M/IO：区分存储器访问和 I/O 访问  
INTA：中断响应  
READY：等待状态  
RESET：复位

8086 地址线和数据线部分复用，所以需要地址锁存器，例如 74LS373。

## 6. 最小模式和最大模式

重点理解：

最小模式：单处理器系统，控制信号由 8086 自己产生。  
最大模式：多处理器或协处理器系统，控制信号由总线控制器产生。

一般考试重点在区别，不一定要求深入画复杂时序。

# 三、8086/8088 指令系统

这是整门课的核心。

## 1. 寻址方式

必须重点掌握。

常见寻址方式：

立即寻址：

MOV AX, 1234H

寄存器寻址：

MOV AX, BX

直接寻址：

MOV AX, [2000H]

寄存器间接寻址：

MOV AX, [BX]  
MOV AX, [SI]

基址寻址：

MOV AX, [BX+1000H]

变址寻址：

MOV AX, [SI+1000H]

MOV AX, [BX+SI]

相对基址变址寻址：

MOV AX, [BX+SI+1000H]

# 四、汇编语言程序设计

## 1. 汇编语言基础

重点掌握：

汇编语言程序由：

指令  
伪指令  
标号  
注释  
数据定义

组成。

常见数据定义：

DB：定义字节  
DW：定义字  
DD：定义双字

例如：

DATA DB 12H  
NUM DW 1234H

## 2. 程序基本结构

三种基本程序结构必须掌握：

顺序结构  
分支结构  
循环结构

### 顺序程序

一条一条执行，没有跳转。

### 分支程序

常用 CMP 配合条件转移。

例如：

CMP AX, BX  
JA NEXT

### 循环程序

常用 CX 作为循环计数器。

例如：

MOV CX, 10  
AGAIN:  
; 循环体  
LOOP AGAIN

## 3. DOS 功能调用

重点掌握 INT 21H。

常见功能：

AH = 01H：键盘输入一个字符  
AH = 02H：显示一个字符  
AH = 09H：显示字符串  
AH = 4CH：程序返回 DOS

显示字符串时，字符串必须以 $ 结尾。

例如：

MOV AH, 09H  
LEA DX, MSG  
INT 21H

## 4. 子程序设计

重点掌握：

CALL  
RET  
PUSH  
POP

子程序调用过程：

CALL 保存返回地址并跳转到子程序。  
RET 从堆栈中取出返回地址并返回主程序。

重点理解堆栈变化。

CALL 会压栈返回地址。  
RET 会弹出返回地址。

## 5. 字符串处理

REP

字符串操作常和 SI、DI、CX 搭配使用。

# 五、存储器技术

## 1. 存储器分类

重点掌握：

RAM：随机存储器，可读可写，掉电数据丢失。  
ROM：只读存储器，掉电数据不丢失。

RAM 分为：

SRAM：静态 RAM，速度快，价格高。  
DRAM：动态 RAM，容量大，价格低，需要刷新。

ROM 分为：

掩膜 ROM  
PROM  
EPROM  
EEPROM

## 2. 存储器容量计算

重点掌握：

容量 = 单元数 × 每单元位数

例如：

2K × 8 表示：

有 2K 个存储单元，每个单元 8 位，总容量为 2KB。

常见换算：

1K = 1024  
1KB = 1024B  
1MB = 1024KB

## 3. CPU 与存储器连接

重点掌握：

地址线决定寻址范围。  
数据线决定一次传送的数据位数。  
控制线决定读写操作。

常考：

地址线数量和存储容量的关系。

如果芯片容量是 8K × 8，则需要 13 根地址线，因为：

8K = 8192 = 2¹³

## 4. 存储器扩展

重点掌握两种扩展：

位扩展  
字扩展，也叫容量扩展

位扩展：

增加数据位宽。

例如用两个 8K×8 芯片组成 8K×16。

字扩展：

增加地址容量。

例如用两个 8K×8 芯片组成 16K×8。

## 5. 地址译码

这是存储器章节的重点。

需要掌握：

全译码  
部分译码  
线选法  
译码器法

常用芯片：

74LS138

常考题型：

给出存储器地址范围，求片选信号。  
给出芯片容量，设计地址连接。  
判断某芯片占用的地址范围。

## 6. Cache 和存储体系

了解为主。

重点理解：

Cache 位于 CPU 和主存之间，用来提高访问速度。  
存储器层次结构一般是：

寄存器 → Cache → 主存 → 外存

越靠近 CPU，速度越快，容量越小，价格越高。

# 六、输入/输出接口技术

## 1. I/O 接口的作用

重点理解：

CPU 不能直接控制复杂外设，必须通过 I/O 接口连接外设。

I/O 接口主要作用：

数据缓冲  
信号转换  
地址译码  
状态检测  
控制外设

## 2. I/O 端口

重点掌握：

I/O 端口是 CPU 与外设交换信息的地址。

端口类型：

数据端口  
状态端口  
控制端口

8086 有两种 I/O 寻址方式：

直接端口寻址  
间接端口寻址

直接端口寻址：

IN AL, 80H  
OUT 80H, AL

间接端口寻址：

MOV DX, 300H  
IN AL, DX  
OUT DX, AL

## 3. I/O 编址方式

重点掌握：

统一编址  
独立编址

8086 使用独立编址方式。

即：

存储器地址空间和 I/O 地址空间分开。

访问存储器用 MOV 等指令。  
访问 I/O 端口用 IN、OUT 指令。

## 4. 输入输出控制方式

重点掌握四种方式：

无条件传送方式  
查询传送方式  
中断传送方式  
DMA 方式

### 无条件传送

CPU 不判断外设状态，直接传送。

适合简单外设。

### 查询方式

CPU 不断查询外设状态。

优点：程序简单。  
缺点：浪费 CPU 时间。

### 中断方式

外设准备好后主动请求 CPU 服务。

优点：CPU 效率高。  
缺点：硬件和程序较复杂。

### DMA 方式

外设和存储器之间直接传送数据，不经过 CPU 逐字节搬运。

适合高速、大批量数据传送。

例如磁盘、数据采集、高速通信。

## 5. 四种 I/O 方式比较

必须会简答。

从低级到高级：

无条件方式 → 查询方式 → 中断方式 → DMA 方式

CPU 占用越来越少，硬件复杂度越来越高。

# 七、中断技术

这是期末高频重点。

## 1. 中断基本概念

重点掌握：

中断是 CPU 在执行当前程序时，由外部事件或内部事件引起，暂停当前程序，转去执行中断服务程序，执行完后再返回原程序继续执行的过程。

中断过程：

中断请求  
中断响应  
保护现场  
执行中断服务程序  
恢复现场  
中断返回

## 2. 中断分类

重点掌握：

外部中断  
内部中断

外部中断包括：

可屏蔽中断 INTR  
不可屏蔽中断 NMI

内部中断包括：

除法溢出  
单步中断  
断点中断  
溢出中断  
软件中断 INT n

## 3. 中断优先级

重点理解：

多个中断同时发生时，CPU 按优先级决定先响应哪个。

NMI 优先级高于 INTR。

可屏蔽中断是否响应受 IF 标志影响。

IF = 1，允许响应可屏蔽中断。  
IF = 0，禁止响应可屏蔽中断。

## 4. 中断向量表

这是重点。

8086 中断向量表位于内存最低地址：

00000H ~ 003FFH

每个中断向量占 4 个字节：

前 2 字节：IP  
后 2 字节：CS

中断类型号为 n 时，中断向量地址为：

n × 4

例如：

INT 21H 的中断向量入口地址：

21H × 4 = 84H

所以在 0000:0084H 处存放 INT 21H 的 IP 和 CS。

## 5. 中断响应过程

必须会写简答题。

8086 响应中断后大致过程：

1. 保护 FLAGS
    
2. 清除 IF 和 TF
    
3. 保护 CS
    
4. 保护 IP
    
5. 根据中断类型号找到中断向量
    
6. 装入新的 CS 和 IP
    
7. 执行中断服务程序
    
8. IRET 返回原程序
    

IRET 会依次恢复：

IP  
CS  
FLAGS

## 6. 中断服务程序

重点掌握：

中断服务程序开头一般要保护现场。

常用：

PUSH AX  
PUSH BX  
PUSH CX  
PUSH DX

结束前恢复现场：

POP DX  
POP CX  
POP BX  
POP AX  
IRET

注意：

中断服务程序最后不是 RET，而是 IRET。
