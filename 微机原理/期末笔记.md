#### BCD 码和 ASCII 码

**BCD 码**：用二进制形式表示十进制数的一种编码方法。常见的是 8421 BCD 码，即用 4 位二进制表示 1 位十进制数字。  
例如：十进制 `59` 的 BCD 码为 `0101 1001`，其中 `0101` 表示 5，`1001` 表示 9。

注意：BCD 码不是普通二进制数。  
例如：`59` 的普通二进制是 `00111011`，而 BCD 码是 `0101 1001`。

**ASCII 码**：美国信息交换标准代码，用 7 位二进制编码表示字符，常用 8 位存储。它主要用于表示英文字母、数字、标点符号和控制字符。  
常见例子：字符 `'0'` 的 ASCII 码是 `30H`，字符 `'A'` 的 ASCII 码是 `41H`，字符 `'a'` 的 ASCII 码是 `61H`。

常考区别：

- BCD 码用于表示十进制数字。
- ASCII 码用于表示字符。
- 数字 `5` 的 BCD 码是 `0101`，字符 `'5'` 的 ASCII 码是 `35H`。

### 4. 数据表示方法

重点掌握：

无符号数和有符号数。

有符号数重点是：

#### 原码、反码、补码
硬件的加法器无法识别符号位的特殊含义

**原码**：最高位是符号位，`0` 表示正数，`1` 表示负数，其余位表示数值大小。  
例如 8 位表示：`+5 = 00000101`，`-5 = 10000101`。

**反码**：正数的反码等于原码；负数的反码是在原码基础上，符号位不变，其余位取反。  
例如：`-5` 原码为 `10000101`，反码为 `11111010`。

**补码**：正数的补码等于原码；负数的补码是在反码基础上加 `1`。  
例如：`-5` 反码为 `11111010`，补码为 `11111011`。

最重要的是**补码运算**。

补码的意义：
	
- 计算机中有符号整数通常用补码表示。
- 补码可以把减法转换成加法，统一加减运算规则。
- 补码只有一个 `0`，避免了原码和反码中 `+0`、`-0` 同时存在的问题。
- 硬件的加法器无法识别符号位的特殊含义

常考：

8 位补码表示范围：-128 ~ +127  
16 位补码表示范围：-32768 ~ +32767

### 逻辑运算

逻辑运算是对二进制位 `0` 和 `1` 进行的按位运算，常用于判断条件、位控制和数据处理。

| 类型 | 常用符号 | 运算方法 |
|---|---|---|
| 与运算 | `AND`，`∧`，`·` | 两个都为 `1`，结果才为 `1`；否则为 `0` |
| 或运算 | `OR`，`∨`，`+` | 只要有一个为 `1`，结果就是 `1` |
| 非运算 | `NOT`，`¬`，上划线 | 按位取反，`0` 变 `1`，`1` 变 `0` |
| 异或运算 | `XOR`，`⊕` | 两位不同为 `1`，相同为 `0` |

常见规律：

- `A AND 0 = 0`，可用于清零。
- `A AND 1 = A`，可用于保留原位。
- `A OR 1 = 1`，可用于置 `1`。
- `A OR 0 = A`，可用于保持原位。
- `A XOR 0 = A`，原位不变。
- `A XOR 1 = 取反`，可用于翻转某一位。
- `A XOR A = 0`，可用于清零。

重点掌握：

8086 使用分段管理方式。

物理地址 = 段地址 × 16 + 偏移地址

也可以写成：

物理地址 = 20000H + 0100H = 20100H

## 5. 8086/8088 引脚和总线

重点掌握：

地址总线  
数据总线  
控制总线

三类总线的作用：

| 总线类型 | 作用 | 方向 | 说明 |
|---|---|---|---|
| 地址总线 | 传送地址信息 | 通常单向，由 CPU 发出 | 用来指出 CPU 要访问的存储单元或 I/O 端口地址 |
| 数据总线 | 传送数据信息 | 双向 | CPU、存储器、I/O 设备之间通过它交换数据 |
| 控制总线 | 传送控制信号和状态信号 | 有单向也有双向 | 用来控制读、写、中断、复位、总线请求等操作 |

简单记忆：

- 地址总线：决定“访问哪里”。
- 数据总线：决定“传什么数据”。
- 控制总线：决定“怎么操作”。

![[微机原理/attachments/Pasted image 20260619145547.png|553]]

常见信号：

ALE：地址锁存允许  
RD：读信号  
WR：写信号  
M/IO：区分存储器访问和 I/O 访问  
INTA：中断响应  
READY：等待状态  
RESET：复位

8086 地址线和数据线部分复用，所以需要地址锁存器，例如 74LS373。

### 数据传送指令简述和举例

| 指令 | 作用 | 例子 |
|---|---|---|
| `MOV` | 数据传送，把源操作数送到目的操作数 | `MOV AX, BX`：把 BX 送入 AX |
| `PUSH` | 入栈，把 16 位数据压入堆栈 | `PUSH AX`：把 AX 压入堆栈 |
| `POP` | 出栈，从堆栈弹出 16 位数据 | `POP AX`：弹出栈顶数据到 AX |
| `XCHG` | 交换两个操作数内容 | `XCHG AX, BX`：交换 AX 和 BX |
| `LEA` | 取有效地址，把偏移地址送入寄存器 | `LEA DX, MSG`：把 MSG 的偏移地址送入 DX |
| `IN` | 从 I/O 端口输入数据到 AL 或 AX | `IN AL, 60H`：从 60H 端口读入数据到 AL |
| `OUT` | 把 AL 或 AX 的数据输出到 I/O 端口 | `OUT 60H, AL`：把 AL 输出到 60H 端口 |
| `LAHF` | 把 FLAGS 的低 8 位送入 AH | `LAHF`：保存部分标志位到 AH |
| `SAHF` | 把 AH 内容送入 FLAGS 的低 8 位 | `SAHF`：用 AH 恢复部分标志位 |
| `PUSHF` | 将 FLAGS 标志寄存器压入堆栈 | `PUSHF`：保存标志寄存器 |
| `POPF` | 从堆栈弹出数据到 FLAGS | `POPF`：恢复标志寄存器 |

重点记忆：

- `MOV` 是最常用的数据传送指令。
- `PUSH`、`POP` 用于堆栈操作，8086 中操作数必须是 **16 位**。
- `IN`、`OUT` 用于 CPU 和 I/O 端口之间的数据传送。
- `PUSHF`、`POPF` 操作的是整个 FLAGS 标志寄存器。

注意：
![[微机原理/attachments/Pasted image 20260619155158.png|456]]

MOV 不能直接实现存储器到存储器传送。

错误示例：

MOV [1000H], [2000H]

需要通过寄存器中转。

### 算术运算指令简述和举例

| 指令 | 作用 | 例子 |
|---|---|---|
| `ADD` | 加法，不带进位 | `ADD AX, BX`：AX = AX + BX |
| `ADC` | 带进位加法，把 CF 也加进去 | `ADC AX, BX`：AX = AX + BX + CF |
| `SUB` | 减法，不带借位 | `SUB AX, BX`：AX = AX - BX |
| `SBB` | 带借位减法，把 CF 也减掉 | `SBB AX, BX`：AX = AX - BX - CF |
| `INC` | 自增 1 | `INC AX`：AX = AX + 1 |
| `DEC` | 自减 1 | `DEC AX`：AX = AX - 1 |
| `CMP` | 比较，本质是做减法但不保存结果 | `CMP AX, BX`：比较 AX 和 BX，影响标志位 |
| `MUL` | 无符号数乘法 | `MUL BL`：AL × BL，结果送 AX |
| `IMUL` | 有符号数乘法 | `IMUL BL`：有符号 AL × BL，结果送 AX |
| `DIV` | 无符号数除法 | `DIV BL`：AX ÷ BL，商送 AL，余数送 AH |
| `IDIV` | 有符号数除法 | `IDIV BL`：有符号 AX ÷ BL，商送 AL，余数送 AH |
| `CBW` | 字节扩展为字，把 AL 符号扩展到 AX | 若 AL 为负数，则 AH 补 `FFH` |
| `CWD` | 字扩展为双字，把 AX 符号扩展到 DX:AX | 若 AX 为负数，则 DX 补 `FFFFH` |

重点记忆：

- `ADD/SUB` 是普通加减法。
- `ADC/SBB` 用于多字节或多字加减法，因为要处理进位或借位。
- `CMP` 只影响标志位，不改变操作数，常和条件转移指令配合使用。
- `MUL/DIV` 用于无符号数，`IMUL/IDIV` 用于有符号数。
- `CBW/CWD` 常用于有符号乘除法前的符号扩展。

重点理解标志位变化：

CF：进位标志  
ZF：零标志  
SF：符号标志  
OF：溢出标志  
PF：奇偶标志  
AF：辅助进位标志

考试常考：

执行一条 ADD、SUB、CMP 后，判断 ZF、CF、SF、OF。

## 4. 逻辑运算指令

逻辑运算是对二进制数按位进行的运算，常用于位控制、屏蔽、置位、取反和测试。

### 类型、符号和方法

| 类型 | 汇编符号 | 运算方法 | 常见用途 |
|---|---|---|---|
| 逻辑与 | `AND` | 两位都为 `1`，结果才为 `1` | 清零某些位、保留某些位 |
| 逻辑或 | `OR` | 两位只要有一个为 `1`，结果就是 `1` | 置 `1` 某些位 |
| 逻辑异或 | `XOR` | 两位不同为 `1`，相同为 `0` | 翻转某些位、寄存器清零 |
| 逻辑非 | `NOT` | 按位取反，`0` 变 `1`，`1` 变 `0` | 求反码、按位取反 |
| 测试 | `TEST` | 本质上做 `AND`，但不保存结果，只影响标志位 | 判断某些位是否为 `1` |

重点掌握：

AND  
OR  
XOR  
NOT  
TEST

常见用途：

AND 用于清零某些位。  
OR 用于置 1 某些位。  
XOR 可用于清零寄存器。  
TEST 只影响标志位，不保存结果。

例如：

XOR AX, AX

作用是 AX 清零。

再例如：

AND AL, 0FH

作用是保留 AL 的低 4 位，高 4 位清零。

OR AL, 80H

作用是把 AL 的最高位置 `1`。

TEST AL, 01H

作用是测试 AL 最低位是否为 `1`，结果不写回 AL，只根据结果影响 ZF 等标志位。

### 移位和循环移位指令对比

| 指令 | 类型 | 移动方向 | 空出位如何处理 | 移出位去向 | 典型用途 |
|---|---|---|---|---|---|
| `SHL` | 逻辑左移 | 左移 | 低位补 `0` | 最高位送 CF | 无符号数乘 2 |
| `SAL` | 算术左移 | 左移 | 低位补 `0` | 最高位送 CF | 与 `SHL` 基本相同，常用于有符号数乘 2 |
| `SHR` | 逻辑右移 | 右移 | 高位补 `0` | 最低位送 CF | 无符号数除 2 |
| `SAR` | 算术右移 | 右移 | 高位补符号位 | 最低位送 CF | 有符号数除 2，保持正负号 |
| `ROL` | 循环左移 | 左移 | 最低位补原最高位 | 原最高位送 CF，同时回到最低位 | 位循环，不经过 CF |
| `ROR` | 循环右移 | 右移 | 最高位补原最低位 | 原最低位送 CF，同时回到最高位 | 位循环，不经过 CF |
| `RCL` | 带进位循环左移 | 左移 | 最低位补原 CF | 最高位送 CF | 把 CF 也作为循环的一部分 |
| `RCR` | 带进位循环右移 | 右移 | 最高位补原 CF | 最低位送 CF | 把 CF 也作为循环的一部分 |

重点对比：

- `SHL` 和 `SAL`：在 8086 中效果基本相同，都是左移，低位补 `0`。
- `SHR` 和 `SAR`：都右移，但 `SHR` 高位补 `0`，`SAR` 高位补符号位。
- `ROL/ROR`：普通循环移位，移出的位会回到另一端。
- `RCL/RCR`：带 CF 的循环移位，CF 参与循环。

例子：

```asm
MOV AL, 10000010B
SHL AL, 1      ; AL = 00000100B，最高位 1 移入 CF

MOV AL, 10000010B
SHR AL, 1      ; AL = 01000001B，高位补 0

MOV AL, 10000010B
SAR AL, 1      ; AL = 11000001B，高位补原符号位 1
```

| 相等/为零转移 | `JE / JZ` | `ZF = 1` | 相等或结果为 0 时跳转 |
| 不等/非零转移 | `JNE / JNZ` | `ZF = 0` | 不相等或结果不为 0 时跳转 |
| 有进位转移 | `JC` | `CF = 1` | 有进位或借位时跳转 |
| 无进位转移 | `JNC` | `CF = 0` | 无进位或无借位时跳转 |
| 负数转移 | `JS` | `SF = 1` | 结果为负时跳转 |
| 非负转移 | `JNS` | `SF = 0` | 结果为非负时跳转 |
| 溢出转移 | `JO` | `OF = 1` | 有溢出时跳转 |
| 无溢出转移 | `JNO` | `OF = 0` | 无溢出时跳转 |
| 有符号大于 | `JG` | `ZF = 0 且 SF = OF` | 有符号数比较，大于时跳转 |
| 有符号小于 | `JL` | `SF ≠ OF` | 有符号数比较，小于时跳转 |
| 无符号高于 | `JA` | `CF = 0 且 ZF = 0` | 无符号数比较，大于时跳转 |
| 无符号低于 | `JB` | `CF = 1` | 无符号数比较，小于时跳转 |
| 循环 | `LOOP` | `CX ≠ 0` | CX 减 1 后不为 0，则跳转 |
| 相等循环 | `LOOPE / LOOPZ` | `CX ≠ 0 且 ZF = 1` | CX 未减到 0 且结果为零/相等时跳转 |
| 不等循环 | `LOOPNE / LOOPNZ` | `CX ≠ 0 且 ZF = 0` | CX 未减到 0 且结果非零/不等时跳转 |

重点区别：

- `JMP`：无条件跳转，不看标志位。
- 条件转移：根据 `ZF、CF、SF、OF` 等标志位决定是否跳转。
- `JG/JL` 用于**有符号数**比较。
- `JA/JB` 用于**无符号数**比较。
- `LOOP` 系列会自动让 `CX = CX - 1`，再判断是否跳转。

重点是理解条件转移和标志位的关系。

## 7. 处理器控制指令

了解即可，但常见的要会：

CLC：清 CF  
STC：置 CF  
CLI：关中断  
STI：开中断  
NOP：空操作

### 处理器控制指令对比

| 指令 | 全称/含义 | 操作对象 | 作用 | 常见用途 |
|---|---|---|---|---|
| `CLC` | Clear Carry Flag | CF | 清进位标志，使 `CF = 0` | 加减运算前手动清除进位/借位 |
| `STC` | Set Carry Flag | CF | 置进位标志，使 `CF = 1` | 人为设置进位/借位条件 |
| `CLI` | Clear Interrupt Flag | IF | 清中断允许标志，使 `IF = 0` | 关闭可屏蔽中断 |
| `STI` | Set Interrupt Flag | IF | 置中断允许标志，使 `IF = 1` | 开启可屏蔽中断 |
| `NOP` | No Operation | 无 | 空操作，不做实际处理 | 延时、占位、调试 |
| `HLT` | Halt | CPU | 使 CPU 暂停运行，等待中断或复位 | 停机等待外部事件 |

重点对比：

- `CLC/STC`：控制 **CF 进位标志**。
- `CLI/STI`：控制 **IF 中断允许标志**。
- `NOP`：什么也不做，但会占用一个指令周期。
- `HLT`：让 CPU 停止执行，直到发生中断或复位。

### 1. 编程思路设计（如何传参？）

高级语言里我们通过 `sum(array, length)` 传参。汇编语言里没有这种高级语法，我们必须利用**寄存器**来充当参数的桥梁：

- 用 **`BX`** 寄存器：传递**数组的首地址**（指针）。
    
- 用 **`CX`** 寄存器：传递**数组的长度**（循环计数器）。
    
- 用 **`AX`** 寄存器：作为返回值，用来**存放累加的和**。
    

### 2. 完整汇编源码

代码段

```
DATA SEGMENT
    ARRAY  DB  10, 20, 30, 40, 50   ; 定义一个 5 个元素的字节数组
    COUNT  DW  5                    ; 数组长度为 5
    SUM    DW  ?                    ; 用来保存最终结果
DATA ENDS

CODE SEGMENT
    ASSUME CS:CODE, DS:DATA
START:
    ; 1. 初始化数据段 DS
    MOV AX, DATA
    MOV DS, AX

    ; 2. 为主程序调用子程序准备“参数”
    LEA BX, ARRAY   ; BX 指向数组首地址
    MOV CX, COUNT   ; CX 赋值为数组长度 (5)

    ; 3. 调用子程序
    CALL ARRAYSUM   ; 硬件动作：将下一条指令的 IP 压栈，然后跳转到 ARRAYSUM

    ; 4. 子程序执行完回来后，结果已经在外面的 AX 里了
    MOV SUM, AX     ; 将累加结果 (AX) 保存到变量 SUM 中

    ; 5. 安全退出程序返回 DOS
    MOV AX, 4C00H
    INT 21H

; ========================================================
; 子程序定义：ARRAYSUM
; 功能：计算一个字节数组的元素之和
; 输入参数：BX = 数组首地址, CX = 数组长度
; 输出参数：AX = 累加和结果
; ========================================================
ARRAYSUM PROC NEAR
    PUSH BX         ; 【保护现场】保护主程序可能正在使用的 BX
    PUSH CX         ; 【保护现场】保护主程序可能正在使用的 CX

    XOR AX, AX      ; 将累加寄存器 AX 清零 (AX = 0)
    XOR DX, DX      ; DX 清零，用来做高位扩展

SUM_LOOP:
    MOV DL, [BX]    ; 从 BX 指向的内存中取出一个字节送入 DL
    ADD AX, DX      ; 累加到 AX 中（用 16 位加法防止 8 位溢出）
    INC BX          ; 指针 BX 指向数组的下一个元素
    LOOP SUM_LOOP   ; 核心循环：CX 自动减 1，只要 CX != 0 就跳回 SUM_LOOP

    POP CX          ; 【恢复现场】先压后弹，按相反顺序弹回原 CX
    POP BX          ; 【恢复现场】弹回原 BX
    
    RET             ; 从堆栈中弹出刚才保存的断点 IP，程序跳回主程序第 4 步
ARRAYSUM ENDP
; ========================================================

CODE ENDS
    END START
```

### 3、 子程序底层的硬件协作：堆栈的变化

子程序之所以能够精准地去、精准地原路返回，全靠堆栈（Stack）在幕后默默记录。它的运行轨迹在硬件层面的变换过程如下：

1. **执行 `CALL ARRAYSUM` 时**：
    
    - CPU 知道自己要暂时离开主程序了，于是自动把 `CALL` 下一行的指令偏移地址（即 `MOV SUM, AX` 这句话的 `IP`）**压入堆栈**。
        
2. **进入子程序执行 `PUSH` 时**：
    
    - 程序员为了防止在子程序里改写 `BX` 和 `CX` 会破坏主程序的数据，执行 `PUSH BX` 和 `PUSH CX`，把主程序的旧数据也压入堆栈保护起来（俗称**保护现场**）。
        
3. **子程序结束前执行 `POP` 时**：
    
    - 按照“后进先出”的铁律，先 `POP CX` 再 `POP BX`，把主程序原汁原味的数据**还原回去**（俗称**恢复现场**）。
        
4. **执行 `RET` 时**：
    
    - 此时栈顶正好露出了第 1 步压进去的**主程序断点 `IP`**。`RET` 指令自动从栈顶把这个 `IP` 弹出来，重新塞进 CPU 的 **`IP` 寄存器**里。
        
    - 于是，CPU 的流水线立刻无缝切回主程序，继续向下执行。

CPU 不断查询外设状态。

# 七、中断技术

这是期末高频重点。

## 1. 中断基本概念

重点掌握：

中断是 CPU 在执行当前程序时，由外部事件或内部事件引起，暂停当前程序，转去执行中断服务程序，执行完后再返回原程序继续执行的过程。

中断过程：

中断请求  
中断响应  
保护现场  
执行中断服务程序  
恢复现场  
中断返回

## 2. 中断分类

重点掌握：

外部中断  
内部中断

外部中断包括：

可屏蔽中断 INTR  
不可屏蔽中断 NMI

内部中断包括：

除法溢出  
单步中断  
断点中断  
溢出中断  
软件中断 INT n
![[微机原理/attachments/Pasted image 20260620221903.png|636]]

## 3. 中断优先级

重点理解：

多个中断同时发生时，CPU 按优先级决定先响应哪个。

NMI 优先级高于 INTR。

可屏蔽中断是否响应受 IF 标志影响。

IF = 1，允许响应可屏蔽中断。  
IF = 0，禁止响应可屏蔽中断。

## 4. 中断向量表

这是重点。

8086 中断向量表位于内存最低地址：

00000H ~ 003FFH

每个中断向量占 4 个字节：

前 2 字节：IP  
后 2 字节：CS

中断类型号为 n 时，中断向量地址为：

n × 4

例如：

INT 21H 的中断向量入口地址：

21H × 4 = 84H

所以在 0000:0084H 处存放 INT 21H 的 IP 和 CS。

## 5. 中断响应过程

必须会写简答题。

8086 响应中断后大致过程：

1. 保护 FLAGS
    
2. 清除 IF 和 TF
    
3. 保护 CS
    
4. 保护 IP
    
5. 根据中断类型号找到中断向量
    
6. 装入新的 CS 和 IP
    
7. 执行中断服务程序
    
8. IRET 返回原程序
    

IRET 会依次恢复：

IP  
CS  
FLAGS

## 6. 中断服务程序

重点掌握：

中断服务程序开头一般要保护现场。

常用：

PUSH AX  
PUSH BX  
PUSH CX  
PUSH DX

结束前恢复现场：

POP DX  
POP CX  
POP BX  
POP AX  
IRET

注意：

中断服务程序最后不是 RET，而是 IRET。

建议按这个顺序复习：

第一步：数制、补码、数据表示  
第二步：8086 寄存器和物理地址计算  
第三步：寻址方式和常用指令  
第四步：汇编程序结构  
第五步：存储器扩展和地址译码  
第六步：I/O 接口和端口地址  
第七步：中断技术

最核心的三块是：

8086 寄存器与地址形成  
8086 指令系统与汇编程序  
存储器、I/O、中断接口技术

如果时间不多，优先复习：

物理地址计算  
补码运算  
寻址方式  
MOV/ADD/SUB/CMP/JMP/LOOP/CALL/RET/INT/IRET  
汇编循环和分支程序  
存储器地址译码  
I/O 四种传送方式  
中断向量表和中断响应过程
