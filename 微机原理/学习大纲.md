6. 掌握 8255 并行接口、中断技术及简单接口程序设计。
    
7. 能够完成汇编程序调试、接口实验分析和软硬件联合调试。

## 第 1 章 计算机的基本结构与操作

### 1.1 数的机器表示

#### 学习内容

1. 计算机中常用的数制：
    
    - 二进制
        
    - 八进制
        
    - 十进制
        
    - 十六进制
        
2. 数制转换：
    
    - 二进制与十进制转换
        - **十→二（整数）**：除 2 取余，逆序排列
            - 例：$25_{10}$ → 25÷2=12余1, 12÷2=6余0, 6÷2=3余0, 3÷2=1余1, 1÷2=0余1 → **11001₂**
        - **十→二（小数）**：乘 2 取整，顺序排列
            - 例：$0.625_{10}$ → 0.625×2=1.25(取1), 0.25×2=0.5(取0), 0.5×2=1.0(取1) → **0.101₂**
        - **二→十**：按位权展开求和（每位 × $2^n$）
            - 例：$1101.101_2$ → $1·2³+1·2²+0·2¹+1·2⁰+1·2^{-1}+0·2^{-2}+1·2^{-3}$ = 8+4+0+1+0.5+0+0.125 = **13.625₁₀**
        
        ![[微机原理/attachments/Pasted image 20260602103044.png]]
        保留小数点后4位
        
    - 二进制与八进制、十六进制转换
        
    - 十进制整数和小数转换 为二进制
        
3. 机器数表示：
    
    - 原码：最高位符号位（0正1负），数值位=绝对值
        - 例：+5 → 0000 0101，-5 → 1000 0101
    - 反码：正数同原码；负数=原码符号位不变，数值位逐位取反
        - 例：-5原=1000 0101 → 反=1111 1010
    - 补码：正数同原码；负数=反码+1（取反加一）
        - 例：-5反=1111 1010 → 补=1111 1011
        - 本质：$[X]_{补} = 2^n + X$（n位）
        - ![[微机原理/attachments/Pasted image 20260602110008.png]]
        - ![[微机原理/attachments/Pasted image 20260602110018.png]]
    - 移码：补码的符号位取反
        - 例：-5补=1111 1011 → 移=0111 1011
        - 用途：浮点数阶码，便于硬件比较大小
        
4. 常用编码：
    
    - BCD 码（Binary-Coded Decimal）：用4位二进制表示1位十进制数
        - **压缩BCD**：1字节存2位（如 56 → 0101 0110）
        - **非压缩BCD**：1字节存1位，高4位为0（如 5 → 0000 0101）
        - 合法范围：0000~1001（0~9），1010~1111为非法BCD
        - 特点：直观，但浪费空间；8086有专用调整指令（DAA/DAS等）
    - 
        
    - ASCII 码（American Standard Code for Information Interchange）
        - 7位编码，共128个字符，微机中1字节存1个ASCII（高位置0）
        - 必记编码：
            | 字符 | 十六进制 | 说明 |
            |:---|:---|:---|
            | `'0'` | **30H** | 数字0，数字N = 30H+N |
            | `'A'` | **41H** | 大写A，大写字母 = 41H+序号 |
            | `'a'` | **61H** | 小写a，小写字母 = 61H+序号 |
            | `' '` | **20H** | 空格 |
            | CR | **0DH** | 回车 |
            | LF | **0AH** | 换行 |
            | BEL | **07H** | 响铃 |
        - 大小写转换：加/减**20H**（大小写正好差32）
        - 数字字符→数值：减**30H**
        - ![[微机原理/attachments/Pasted image 20260602115505.png]]
        
    - 汉字编码的基本概念
        - **为什么需要专用编码**：ASCII只有128个字符，汉字数以万计，必须用**多字节**表示
        - **三种编码形态**（同指一个汉字）：
            | 形态 | 用途 | 举例 |
            |:---|:---|:---|
            | **输入码**（外码） | 用户输入 | 拼音、五笔 |
            | **机内码**（内码） | 机内存储 | 国标码+8080H，每个字节最高位置1以区分ASCII |
            | **字形码**（输出码） | 显示/打印 | 16×16点阵（占32字节） |
        - **常用编码标准**：GB2312（6763汉字）→ GBK（扩展）→ GB18030（最新国标）  
          UTF-8:国际 通用  3个字节
        - **核心原则**：两个字节  汉字内码每个字节高位均为1，从而与ASCII（高位为0）互不冲突
        

#### 学习重点

- 二进制、十六进制与十进制之间的相互转换。
    
- 有符号数的原码、反码、补码表示。
    
- 补码表示范围和溢出判断。
    - **n位补码范围**：$[-2^{n-1}, 2^{n-1}-1]$（8位：-128～+127，16位：-32768～+32767）
    - **溢出条件**：两个同号数相加，结果符号与操作数不同 → 溢出
        - 例：+120 + +20 = +140(补)=1000 1100，结果符号位=1(负)，与两正操作数不同 → **OF=1，溢出**
        - 例：-120 + -20，-120补=1000 1000，-20补=1110 1100，和=0111 0100(正)，与两负不同 → **OF=1，溢出**
    - **硬件判断**：$OF = C_{n} \oplus C_{n-1}$（最高位进位 ⊕ 次高位进位）
        - 无符号数看**CF**（进位/借位），有符号数看**OF**（溢出）
    
- ASCII 码中数字、字母、回车、换行、响铃等常用字符编码。
- 
- 异或和同或
    ![[微机原理/attachments/Pasted image 20260602112212.png]]
    
    乘除法：先转十进制 运算后转为二进制

#### 易错点

- 正数的原码、反码、补码相同，负数不同。
    
- n 位补码的表示范围是：  
    [-2^{n-1}, 2^{n-1}-1]
    
- ASCII 码中字符 `'0'` 的编码是 30H，不等于数值 0。

## 第 2 章 8086 CPU

### 2.1 8086 CPU 的结构

#### 学习内容

8086 CPU 由两大部分组成：

1. **总线接口单元 BIU**
    
    - 负责取指令
        
    - 负责地址形成
        
    - 负责总线操作
        
    - 包含 6 字节指令队列
        
2. **执行单元 EU**
    
    - 负责指令译码与执行
        
    - 负责算术逻辑运算
        
    - 负责标志位设置
        

#### 8086 主要寄存器

1. 通用寄存器：
    
    - AX：累加器
        
    - BX：基址寄存器
        
    - CX：计数寄存器
        
    - DX：数据寄存器
        
2. 指针和变址寄存器：
    
    - SP：堆栈指针
        
    - BP：基址指针
        
    - SI：源变址寄存器
        
    - DI：目的变址寄存器
        
3. 段寄存器：
    
    - CS：代码段寄存器
        
    - DS：数据段寄存器
        
    - SS：堆栈段寄存器
        
    - ES：附加段寄存器
        
4. 控制寄存器：
    
    - IP：指令指针寄存器
        
    - FLAGS：标志寄存器
        

#### 学习重点

- 8086 是 16 位微处理器，但有 20 根地址线，可寻址 1MB 存储空间。
    
- BIU 和 EU 并行工作，提高了 CPU 执行效率。
    
- 掌握各寄存器的功能及常见用途。

## 第 4 章 汇编语言程序设计

### 4.1 宏汇编语言程序格式

#### 基本结构

一个典型汇编程序通常包括：

1. 数据段
    
2. 堆栈段
    
3. 代码段
    
4. 程序入口
    
5. 程序结束语句
    

#### 示例结构

```asm
DATA SEGMENT
    ; 数据定义
DATA ENDS

STACK SEGMENT
    ; 堆栈定义
STACK ENDS

CODE SEGMENT
ASSUME CS:CODE, DS:DATA, SS:STACK

START:
    MOV AX, DATA
    MOV DS, AX

    ; 程序主体

    MOV AH, 4CH
    INT 21H

CODE ENDS
END START
```

#### 学习重点

- ASSUME 只是告诉汇编程序段寄存器与段的对应关系，并不会真正给段寄存器赋值。
    
- DS 必须在程序运行时通过指令初始化。
    
- 程序结束通常使用 `MOV AH,4CH` 和 `INT 21H`。

- END：源程序结束
    

#### 学习重点

- 伪指令不直接生成 CPU 执行的机器指令，而是指导汇编程序工作。
    
- DB、DW、DD 决定数据所占字节数。
    
- DUP 常用于定义缓冲区或初始化数组。

### 4.4 DOS 系统功能调用与中断调用

#### 常用 INT 21H 功能

1. AH = 01H  
    从键盘输入一个字符，并回显。
    
2. AH = 02H  
    显示一个字符，字符放在 DL 中。
    
3. AH = 09H  
    显示字符串，字符串以 `$` 结束。
    
4. AH = 0AH  
    缓冲区输入字符串。
    
5. AH = 4CH  
    程序返回 DOS。
    

#### 学习重点

- 调用系统功能前，应先设置 AH 功能号。
    
- 参数通常放在寄存器中。
    
- 字符串输出功能 09H 要求字符串以 `$` 结束。
    
- 回车 CR 的 ASCII 码是 0DH，换行 LF 的 ASCII 码是 0AH，响铃 BEL 的 ASCII 码是 07H。

1. 顺序程序

3. 循环程序  
    重复执行某段程序。
    
4. 子程序  
    用 CALL 调用，用 RET 返回。
    
5. 模块化程序  
    将复杂任务分解为多个功能模块。
    

#### 学习重点

- 分支程序常与 CMP、TEST、条件转移指令配合使用。
    
- 循环程序常用 CX 作为计数器。
    
- 子程序应注意保护现场和恢复现场。
    
- 模块化程序有利于调试和复用。

### 6.2 I/O 传送方式与 8255 并行接口

#### 6.2.1 程序控制 I/O 方式

CPU 主动查询外设状态，适用于低速、简单外设。

#### 6.2.2 中断控制 I/O 方式

外设准备好后主动请求 CPU 服务，提高 CPU 利用率。

#### 6.2.3 DMA 方式

外设与存储器直接交换数据，适用于高速、大批量数据传送。

#### 6.2.4 可编程并行接口芯片 8255

8255 包含：

- A 口
    
- B 口
    
- C 口
    
- 控制寄存器
    

工作方式包括：

1. 方式 0：基本输入输出方式。
    
2. 方式 1：选通输入输出方式。
    
3. 方式 2：双向传送方式。
    

#### 学习重点

- 8255 的端口方向由控制字决定。
    
- 方式 0 是最常用、最基础的工作方式。
    
- 设计 8255 接口程序时应先写控制字，再进行数据输入输出。

# 七、核心知识速记

1. 8086 是 16 位 CPU，20 根地址线，最大寻址空间为 1MB。
    
2. 物理地址 = 段地址 × 16 + 偏移地址。
    
3. AX、BX、CX、DX 是通用寄存器。
    
4. CS:IP 指向下一条要执行的指令。
    
5. SS:SP 指向栈顶。
    
6. MOV 不能直接实现内存到内存的数据传送。
    
7. PUSH 和 POP 以字为单位操作。
    
8. CMP 影响标志位，但不保存结果。
    
9. TEST 影响标志位，但不保存结果。
    
10. CF 用于无符号数运算判断，OF 用于有符号数运算判断。
    
11. 8086 栈向低地址方向增长。
    
12. DOS 字符输出常用 INT 21H 的 02H 功能。
    
13. DOS 字符串输出常用 INT 21H 的 09H 功能，字符串必须以 `$` 结束。
    
14. 程序返回 DOS 常用 INT 21H 的 4CH 功能。
    
15. 8255 使用前必须先写入控制字。
    
16. 中断服务程序结束使用 IRET。
    
17. 中断向量表位于内存最低 1KB。
    
18. 矩阵键盘扫描需要考虑按键消抖。
    
19. LED 是否点亮与硬件连接方式有关。
    
20. 接口程序设计必须结合端口地址、硬件电路和控制逻辑综合分析。
