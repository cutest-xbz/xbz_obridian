下面是做 **STM32 循迹小车**必须掌握的 **TB6612 电机驱动模块知识点**。

# TB6612 知识点

## 一、TB6612 是什么

TB6612 是一种**双路直流电机驱动芯片**。

简单理解：

```text
STM32 的 GPIO 电流很小，不能直接驱动电机。
所以需要 TB6612 这种电机驱动模块。
STM32 负责发控制信号，TB6612 负责给电机供电和换向。
```

它可以控制两个直流电机：

```text
A 路电机：左电机
B 路电机：右电机
```

在循迹小车中，TB6612 主要负责：

```text
1. 控制左电机正转、反转、刹车
2. 控制右电机正转、反转、刹车
3. 接收 PWM 信号调节电机速度
```

你这个项目中，左电机 PWM 用 `PA6 / TIM3_CH1`，右电机 PWM 用 `PA7 / TIM3_CH2`，电机方向控制引脚使用 `PD9/PD11` 和 `PD12/PD10`。

---

# 二、TB6612 常见引脚

TB6612 模块一般有这些引脚：

```text
VM      电机电源
VCC     逻辑电源
GND     地线
STBY    待机控制
PWMA    A 路电机 PWM 调速
AIN1    A 路电机方向控制 1
AIN2    A 路电机方向控制 2
AO1     A 路电机输出端 1
AO2     A 路电机输出端 2

PWMB    B 路电机 PWM 调速
BIN1    B 路电机方向控制 1
BIN2    B 路电机方向控制 2
BO1     B 路电机输出端 1
BO2     B 路电机输出端 2
```

---

# 三、TB6612 引脚作用

## 1. VM：电机电源

VM 给电机供电。

例如：

```text
VM 接 6V、7.4V 或其他适合电机的电源
```

注意：

```text
VM 不是给 STM32 供电的
VM 是给电机供电的
```

---

## 2. VCC：逻辑电源

VCC 给 TB6612 的控制逻辑供电。

一般接：

```text
STM32 的 3.3V
或模块允许的 5V
```

如果你用 STM32F103，建议逻辑控制统一按 3.3V 思路处理。

---

## 3. GND：地线

所有模块必须共地：

```text
STM32 GND
TB6612 GND
电池负极
传感器 GND
```

必须连在一起。

否则 STM32 发出的高低电平对 TB6612 来说没有统一参考，电机可能不转、乱转或者失控。

---

## 4. STBY：待机引脚

STBY 是 TB6612 的使能引脚。

```text
STBY = 1：正常工作
STBY = 0：待机，不驱动电机
```

很多 TB6612 模块会把 STBY 通过跳线或电阻默认拉高。

如果你的模块 STBY 没有接高电平，电机可能完全不转。

---

## 5. PWMA / PWMB：速度控制

PWMA 控制 A 路电机速度。

PWMB 控制 B 路电机速度。

它们接 STM32 的 PWM 输出引脚。

例如你的项目：

```text
PWMA ← PA6 / TIM3_CH1
PWMB ← PA7 / TIM3_CH2
```

PWM 占空比越大，电机速度越快。

---

## 6. AIN1 / AIN2 / BIN1 / BIN2：方向控制

方向引脚由普通 GPIO 控制。

例如：

```text
AIN1、AIN2 控制左电机方向
BIN1、BIN2 控制右电机方向
```

你的项目中：

```text
左电机 IN1/IN2：PD9 / PD11
右电机 IN1/IN2：PD12 / PD10
```

这些引脚要配置成 GPIO 推挽输出。

---

# 四、TB6612 控制逻辑表

以 A 路电机为例：

|AIN1|AIN2|PWMA|电机状态|
|---|---|---|---|
|0|0|任意|滑行 / 停止|
|1|0|PWM|正转|
|0|1|PWM|反转|
|1|1|任意|刹车|

B 路电机同理：

|BIN1|BIN2|PWMB|电机状态|
|---|---|---|---|
|0|0|任意|滑行 / 停止|
|1|0|PWM|正转|
|0|1|PWM|反转|
|1|1|任意|刹车|

---

# 五、正转、反转、刹车、滑行的区别

## 1. 正转

```text
IN1 = 1
IN2 = 0
PWM = 有占空比
```

电机向一个方向转。

---

## 2. 反转

```text
IN1 = 0
IN2 = 1
PWM = 有占空比
```

电机向相反方向转。

---

## 3. 刹车

```text
IN1 = 1
IN2 = 1
```

电机会快速停止。

适合循迹小车紧急停车、终点停车、脱线停车。

你的项目中也采用了刹车逻辑：`Motor_SetSpeed()` 的 speed 为 0 时进入刹车状态。

---

## 4. 滑行

```text
IN1 = 0
IN2 = 0
```

电机会慢慢停下。

滑行不是立刻停，适合不要求快速停止的场合。

---

# 六、TB6612 和 PWM 的关系

TB6612 不能自己决定速度，它只是执行 STM32 发来的 PWM。

```text
STM32 定时器产生 PWM
PWM 输入到 TB6612 的 PWMA/PWMB
TB6612 按照 PWM 占空比控制电机平均电压
电机速度发生变化
```

简单记：

```text
IN1 / IN2 决定方向
PWM 决定速度
STBY 决定是否工作
```

---

# 七、TB6612 在循迹小车中的作用

循迹小车要通过左右轮速度差来转弯。

基本公式：

```text
左轮速度 = 基础速度 + 转向量
右轮速度 = 基础速度 - 转向量
```

例如：

```text
basePwm = 0.5
turn = 0.2

左轮 PWM = 0.7
右轮 PWM = 0.3
```

这样左轮快、右轮慢，小车就会转向。

你的项目中就是通过这种差速方式控制循迹小车转向，并且对速度进行了限幅。

# 九、TB6612 GPIO 初始化思路

方向控制引脚需要配置成普通推挽输出。

```c
void Motor_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOD, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_9 | GPIO_Pin_10 |
                                  GPIO_Pin_11 | GPIO_Pin_12;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_Out_PP;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

    GPIO_Init(GPIOD, &GPIO_InitStructure);
}
```

# 十二、封装 Motor_SetSpeed 思路

实际项目不建议到处直接写 GPIO 控制，而是封装成函数：

```text
speed > 0：正转
speed < 0：反转
speed = 0：刹车
```

伪代码如下：

```c
void Motor_SetSpeed(float speed)
{
    if(speed > 0)
    {
        // 正转
        IN1 = 1;
        IN2 = 0;
        PWM = speed;
    }
    else if(speed < 0)
    {
        // 反转
        IN1 = 0;
        IN2 = 1;
        PWM = -speed;
    }
    else
    {
        // 刹车
        IN1 = 1;
        IN2 = 1;
        PWM = 0;
    }
}
```

你的项目中也是这种 Signed Speed 接口思想：速度值的正负表示方向，绝对值表示速度大小。

# 十三、TB6612 常见问题

## 1. 电机完全不转

常见原因：

```text
1. VM 电机电源没接
2. VCC 逻辑电源没接
3. GND 没共地
4. STBY 没拉高
5. PWM 没输出
6. IN1/IN2 状态错误
7. 电机线没接好
8. 电池电压太低
```

---

## 2. 电机只会一个方向转

可能原因：

```text
1. IN1 或 IN2 某根线没接好
2. GPIO 初始化错
3. 方向控制逻辑写反
4. TB6612 某一路损坏
```

---

## 3. 左右轮方向相反

可能原因：

```text
1. 左右电机安装方向相反
2. 电机线接反
3. AIN/BIN 控制逻辑不一致
```

解决方法：

```text
方法一：交换某个电机的两根输出线
方法二：在代码里反转该电机方向
```

---

## 4. 小车直走跑偏

可能原因：

```text
1. 左右电机性能不同
2. 左右轮摩擦不同
3. 底盘装配不对称
4. 左右 PWM 实际速度不同
```

解决方法：

```text
给左右电机单独加速度补偿
例如左轮 0.50，右轮 0.55
```

---

## 5. 电机一启动 STM32 就复位

可能原因：

```text
1. 电机启动电流太大
2. 单片机和电机共用电源导致电压跌落
3. 电源滤波不够
4. 电池放电能力不足
```

解决方法：

```text
1. 电机电源和 STM32 电源分开稳压
2. GND 共地
3. 在电机电源附近加大电容
4. 使用放电能力更强的电池
5. 降低启动 PWM，慢慢加速
```

# 十四、TB6612 学习重点总结

做循迹小车，TB6612 重点掌握这些：

```text
1. TB6612 是双路直流电机驱动
2. VM 接电机电源
3. VCC 接逻辑电源
4. GND 必须和 STM32 共地
5. STBY 必须拉高才能工作
6. PWMA/PWMB 接 STM32 PWM 引脚
7. AIN1/AIN2 控制 A 路方向
8. BIN1/BIN2 控制 B 路方向
9. PWM 控制速度
10. IN1/IN2 控制方向
11. 1/0 正转，0/1 反转，1/1 刹车，0/0 滑行
12. 小车转弯靠左右轮 PWM 差速
```

# 十五、最小掌握版本

如果只想先把小车跑起来，记住这几句话：

```text
TB6612 负责驱动两个直流电机。
VM 接电机电源，VCC 接逻辑电源，GND 必须共地。
STBY 必须为高电平。
IN1 和 IN2 控制方向。
PWM 控制速度。
左轮和右轮 PWM 不一样，小车就会转弯。
```

一句话总结：

```text
STM32 管控制信号，TB6612 管大电流驱动；GPIO 管方向，PWM 管速度。
```
