下面是做 **STM32 循迹小车**必须掌握的 **差速转向知识点**。

# 差速转向知识点

## 一、什么是差速转向

差速转向就是：

```text
通过控制左右两个轮子的速度差，让小车转弯。
```

循迹小车一般没有方向盘，也没有舵机，主要靠左右轮速度不同来改变方向。

例如：

```text
左轮快，右轮慢：小车向右转
右轮快，左轮慢：小车向左转
左右轮一样快：小车直走
左右轮都停：小车停止
```

你的循迹小车是四轮 2WD 差速驱动，左、右电机分别由 PWM 控制速度。

---

# 二、差速转向的基本原理

小车左右两边轮子速度不同，小车就会绕某个点转动。

可以这样理解：

```text
左轮速度 = 右轮速度：直走
左轮速度 > 右轮速度：向右转
左轮速度 < 右轮速度：向左转
```

如果左右轮方向相反，还可以原地转向：

```text
左轮正转，右轮反转：原地右转
左轮反转，右轮正转：原地左转
```

但普通循迹小车一般不需要频繁原地转，主要靠左右轮快慢差实现平滑转弯。

---

# 三、差速转向和 PWM 的关系

电机速度由 PWM 占空比控制：

```text
PWM 占空比越大，电机越快
PWM 占空比越小，电机越慢
```

所以差速转向本质上就是：

```text
给左电机和右电机设置不同的 PWM 占空比
```

例如：

```text
左轮 PWM = 70%
右轮 PWM = 40%
```

左轮更快，右轮更慢，小车会向右转。

---

# 四、差速转向核心公式

循迹小车最常用公式是：

```text
左轮速度 = 基础速度 + 转向修正量
右轮速度 = 基础速度 - 转向修正量
```

也就是：

```c
left  = basePwm + turn;
right = basePwm - turn;
```

你的项目中采用的就是这个差速转向策略，并且会对速度进行限幅。

---

# 五、basePwm 是什么

`basePwm` 是小车的基础前进速度。

可以理解为：

```text
小车不转弯时，左右轮共同使用的基础速度。
```

例如：

```text
basePwm = 0.5
```

表示左右轮默认以 50% 的 PWM 占空比前进。

如果没有转向修正：

```text
turn = 0

left  = 0.5 + 0 = 0.5
right = 0.5 - 0 = 0.5
```

小车直走。

---

# 六、turn 是什么

`turn` 是转向修正量。

它通常由红外传感器误差和 PID 算法计算出来。

```text
error → PID → turn
```

例如：

```text
黑线偏左，error > 0
PID 输出 turn > 0
```

然后：

```text
left  = basePwm + turn
right = basePwm - turn
```

左右轮速度发生变化，小车开始修正方向。

---

# 七、举例理解差速转向

假设：

```text
basePwm = 0.5
turn = 0.2
```

则：

```text
left  = 0.5 + 0.2 = 0.7
right = 0.5 - 0.2 = 0.3
```

结果：

```text
左轮快，右轮慢，小车向右转。
```

---

再假设：

```text
basePwm = 0.5
turn = -0.2
```

则：

```text
left  = 0.5 + (-0.2) = 0.3
right = 0.5 - (-0.2) = 0.7
```

结果：

```text
左轮慢，右轮快，小车向左转。
```

---

# 八、差速转向和红外误差的关系

红外传感器负责判断黑线位置。

例如 8 路红外检测结果：

```text
黑线在中间：error ≈ 0
黑线偏左：error > 0
黑线偏右：error < 0
```

然后 PID 根据 error 算出 turn：

```text
error 越大，turn 越大，转向越明显
error 越小，turn 越小，转向越轻微
```

完整关系是：

```text
红外传感器状态
        ↓
计算黑线位置 error
        ↓
PID 计算 turn
        ↓
left = basePwm + turn
right = basePwm - turn
        ↓
左右轮速度不同
        ↓
小车转向修正
```

---

# 九、差速转向方向表

假设使用公式：

```text
left = basePwm + turn
right = basePwm - turn
```

则：

|turn 值|左轮|右轮|小车动作|
|---|---|---|---|
|0|正常|正常|直走|
|大于 0|变快|变慢|向右转|
|小于 0|变慢|变快|向左转|
|很大|一边很快一边很慢|急转||
|过大|可能一边为 0|接近原地转||

---

# 十、为什么要限幅

计算出来的 `left` 和 `right` 可能超出正常范围。

例如：

```text
basePwm = 0.6
turn = 0.7
```

则：

```text
left  = 1.3
right = -0.1
```

但是 PWM 一般只允许：

```text
0.0 ~ 1.0
```

所以必须限幅：

```text
如果 left > 1.0，就限制为 1.0
如果 left < 0.0，就限制为 0.0
如果 right > 1.0，就限制为 1.0
如果 right < 0.0，就限制为 0.0
```

你的项目中速度限制在 `[0, speedMax]` 范围内。

---

# 十一、限幅代码示例

```c
float Limit(float value, float min, float max)
{
    if(value > max) return max;
    if(value < min) return min;
    return value;
}
```

使用：

```c
left  = Limit(left,  0.0f, speedMax);
right = Limit(right, 0.0f, speedMax);
```

---

# 十二、差速转向代码示例

```c
void CarDrive_DiffDrive(float basePwm, float turn)
{
    float left;
    float right;

    left  = basePwm + turn;
    right = basePwm - turn;

    left  = Limit(left,  0.0f, 1.0f);
    right = Limit(right, 0.0f, 1.0f);

    Motor_SetSpeed(MOTOR_LEFT, left);
    Motor_SetSpeed(MOTOR_RIGHT, right);
}
```

这段代码的核心就是：

```text
基础速度负责前进
转向修正量负责左右速度差
限幅负责防止 PWM 超范围
```

---

# 十三、差速转向和电机方向

普通循迹时，一般左右电机都正转，只是速度不同。

```text
左轮正转 + 右轮正转：前进循迹
左轮快 + 右轮慢：转向
```

如果遇到急弯，也可以允许一侧停止：

```text
左轮转，右轮停：小半径右转
右轮转，左轮停：小半径左转
```

如果要原地转弯，则需要一边正转一边反转：

```text
左轮正转，右轮反转：原地右转
左轮反转，右轮正转：原地左转
```

但原地转弯容易抖动，初学循迹小车建议先用：

```text
一边快，一边慢
```

不要一开始就用反转。

# 十四、差速转向调参

## 1. basePwm 太大

现象：

```text
小车速度太快
过弯冲出去
来不及修正
容易脱线
```

解决：

```text
降低 basePwm
例如从 0.5 降到 0.35
```

---

## 2. basePwm 太小

现象：

```text
小车跑得太慢
电机可能启动不了
转弯无力
```

解决：

```text
适当增大 basePwm
例如从 0.3 增到 0.45
```

---

## 3. turn 太大

现象：

```text
小车左右疯狂摆动
转向过猛
走 S 型
```

解决：

```text
减小 Kp
增大 Kd
限制 turn 最大值
```

---

## 4. turn 太小

现象：

```text
小车修正不及时
弯道转不过来
慢慢偏出黑线
```

解决：

```text
增大 Kp
降低 basePwm
适当增大 turn 输出限幅
```

---

# 十五、左右电机补偿

实际小车经常出现：

```text
给左右轮相同 PWM，小车仍然跑偏。
```

原因：

```text
左右电机性能不同
左右轮摩擦不同
底盘安装不对称
轮子直径略有差异
```

可以给左右电机加补偿：

```c
left  = left  * leftCompensation;
right = right * rightCompensation;
```

例如：

```text
左轮偏慢：leftCompensation = 1.05
右轮正常：rightCompensation = 1.00
```

或者简单写：

```c
left  = left + 0.03f;
right = right;
```

# 十六、差速转向常见错误

## 1. 小车转向反了

可能原因：

```text
left/right 公式写反
turn 正负方向反了
红外权重正负反了
左右电机接反了
```

解决方法：

```text
方法一：把 turn 改成 -turn
方法二：交换 left 和 right 的公式
方法三：修改红外权重正负
方法四：检查左右电机接线
```

---

## 2. 小车只会原地转圈

可能原因：

```text
左右电机方向相反
某一侧电机接线反了
Motor_SetSpeed() 方向逻辑写错
```

解决：

```text
先脱离循迹算法，单独测试两个电机是否都能向前转。
```

---

## 3. 小车直线跑不直

可能原因：

```text
左右电机速度不一致
PWM 输出不一致
底盘偏
轮子摩擦不同
```

解决：

```text
加入左右电机补偿。
```

---

## 4. 小车过弯冲出线

可能原因：

```text
basePwm 太大
turn 最大值太小
Kp 太小
红外传感器装得太靠后
```

解决：

```text
降低基础速度
提高转向修正
让红外传感器尽量装在车头前方
```

---

# 十七、调试差速转向的步骤

建议按这个顺序调：

```text
1. 不接红外，先让左右电机同速前进
2. 确认小车能基本直走
3. 单独测试 left > right，小车是否向右转
4. 单独测试 left < right，小车是否向左转
5. 加入红外 error，但先不用 PID
6. 根据 error 手动给 turn
7. 确认转向方向正确
8. 再加入 PD / PID 控制
9. 最后调 basePwm、Kp、Kd
```

---

# 十八、差速转向最小掌握版本

只为了把循迹小车跑起来，重点记住：

```text
1. 循迹小车靠左右轮速度差转弯
2. 左右轮一样快，小车直走
3. 左轮快、右轮慢，小车右转
4. 右轮快、左轮慢，小车左转
5. 基础速度 basePwm 决定整体快慢
6. 转向量 turn 决定左右速度差
7. left = basePwm + turn
8. right = basePwm - turn
9. PWM 必须限幅到 0.0 ~ 1.0
10. 先调直走，再调转向，最后调 PID
```

一句话总结：

```text
差速转向就是：用同一个基础速度让车前进，再用一个转向修正量让左右轮产生速度差。
```
