下面是做 **STM32 循迹小车**必须掌握的 **红外读取知识点**。

# 红外读取知识点

## 一、红外循迹传感器是什么

循迹小车一般使用红外对管检测地面颜色。

基本原理：

```text
白色地面：反射红外光强
黑色线条：吸收红外光强
```

所以传感器可以判断当前位置是：

```text
白色区域
黑色线条
```

循迹小车就是根据多个红外传感器检测到的黑线位置，判断车身偏左还是偏右，然后调整左右轮速度。

---

# 二、红外模块常见输出方式

## 1. 数字输出 DO

数字输出只有两种状态：

```text
高电平 1
低电平 0
```

常见情况：

```text
检测到黑线：输出 0
检测到白底：输出 1
```

也有部分模块相反：

```text
检测到黑线：输出 1
检测到白底：输出 0
```

所以实际使用前一定要测试。

---

## 2. 模拟输出 AO

模拟输出是一个电压值。

```text
白色反光强，电压可能较高
黑色反光弱，电压可能较低
```

模拟输出需要 ADC 读取。

循迹小车入门阶段一般使用数字输出 DO，程序更简单。

---

# 三、红外传感器接线

你这个 STM32F103ZE 循迹小车项目中，8 路红外传感器接在：

```text
S1 ~ S8  →  PD0 ~ PD7
```

并且使用 GPIOD 上拉输入。项目说明中也写明了 8 路红外传感器用于加权求和连续位置估计。

可以理解为：

|传感器|STM32 引脚|位置|
|---|---|---|
|S1|PD0|最左侧|
|S2|PD1|左侧|
|S3|PD2|左中|
|S4|PD3|中左|
|S5|PD4|中右|
|S6|PD5|右中|
|S7|PD6|右侧|
|S8|PD7|最右侧|

---

# 四、GPIO 输入模式

红外数字输出接 STM32 时，GPIO 一般配置成输入模式。

常用模式：

```text
GPIO_Mode_IPU：上拉输入
GPIO_Mode_IPD：下拉输入
GPIO_Mode_IN_FLOATING：浮空输入
```

循迹小车推荐先用：

```text
GPIO_Mode_IPU
```

也就是上拉输入。

原因：

```text
默认有稳定高电平
外部传感器拉低时能读到低电平
抗干扰能力比浮空输入好
```

---

# 五、红外 GPIO 初始化

如果 8 路红外接在 PD0~PD7，可以这样初始化：

```c
void Tracker_GPIO_Init(void)
{
    GPIO_InitTypeDef GPIO_InitStructure;

    RCC_APB2PeriphClockCmd(RCC_APB2Periph_GPIOD, ENABLE);

    GPIO_InitStructure.GPIO_Pin = GPIO_Pin_0 | GPIO_Pin_1 | GPIO_Pin_2 | GPIO_Pin_3 |
                                  GPIO_Pin_4 | GPIO_Pin_5 | GPIO_Pin_6 | GPIO_Pin_7;
    GPIO_InitStructure.GPIO_Mode = GPIO_Mode_IPU;
    GPIO_InitStructure.GPIO_Speed = GPIO_Speed_50MHz;

    GPIO_Init(GPIOD, &GPIO_InitStructure);
}
```

注意：

```text
输入模式下 GPIO_Speed 影响不大，但 SPL 初始化结构体通常仍会写上。
```

# 六、读取单个红外传感器

例如读取 S1，也就是 PD0：

```c
uint8_t s1;

s1 = GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_0);
```

判断：

```c
if(GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_0) == Bit_RESET)
{
    // PD0 读到低电平
}
else
{
    // PD0 读到高电平
}
```

如果你的模块是：

```text
黑线 = 0
白底 = 1
```

那么：

```c
if(GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_0) == Bit_RESET)
{
    // S1 检测到黑线
}
```

# 七、一次读取 8 路红外

因为 S1~S8 接在 PD0~PD7，所以可以一次读取 GPIOD 的低 8 位。

```c
uint8_t Tracker_ReadRaw(void)
{
    return (uint8_t)(GPIO_ReadInputData(GPIOD) & 0x00FF);
}
```

解释：

```text
GPIO_ReadInputData(GPIOD)：读取整个 GPIOD 端口
& 0x00FF：只保留 PD0~PD7
```

假设读取结果为：

```text
11100111
```

如果黑线为低电平 0，则说明中间附近的传感器检测到了黑线。

---

# 八、黑线有效电平

红外读取最容易错的地方是：不知道黑线到底输出 0 还是 1。

所以建议定义一个宏：

```c
#define TRACKER_BLACK_LEVEL   Bit_RESET
```

如果你的模块检测黑线输出低电平：

```c
#define TRACKER_BLACK_LEVEL   Bit_RESET
```

如果你的模块检测黑线输出高电平：

```c
#define TRACKER_BLACK_LEVEL   Bit_SET
```

这样以后只改一个地方即可。

判断函数可以这样写：

```c
uint8_t Tracker_IsBlack(GPIO_TypeDef *GPIOx, uint16_t GPIO_Pin)
{
    return GPIO_ReadInputDataBit(GPIOx, GPIO_Pin) == TRACKER_BLACK_LEVEL;
}
```

# 九、8 路红外状态读取示例

```c
void Tracker_ReadAll(uint8_t active[8])
{
    active[0] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_0) == TRACKER_BLACK_LEVEL);
    active[1] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_1) == TRACKER_BLACK_LEVEL);
    active[2] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_2) == TRACKER_BLACK_LEVEL);
    active[3] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_3) == TRACKER_BLACK_LEVEL);
    active[4] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_4) == TRACKER_BLACK_LEVEL);
    active[5] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_5) == TRACKER_BLACK_LEVEL);
    active[6] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_6) == TRACKER_BLACK_LEVEL);
    active[7] = (GPIO_ReadInputDataBit(GPIOD, GPIO_Pin_7) == TRACKER_BLACK_LEVEL);
}
```

其中：

```text
active[i] = 1：第 i 路检测到黑线
active[i] = 0：第 i 路没有检测到黑线
```

# 十、红外状态和小车动作关系

最简单的判断方式：

```text
中间传感器检测到黑线：直走
左边传感器检测到黑线：向左修正
右边传感器检测到黑线：向右修正
全部白色：脱线
全部黑色：终点或特殊标记
```

例如：

```text
00011000：黑线在中间，直走
00110000：黑线偏左，左转修正
00001100：黑线偏右，右转修正
00000000：全白，脱线
11111111：全黑，终点
```

注意：这里的 1 表示检测到黑线，不是 GPIO 原始电平。

# 十一、加权法读取黑线位置

8 路红外不建议只写很多 if 判断，更推荐用加权法。

你的项目中使用的权重是：

```c
{7, 5, 3, 1, -1, -3, -5, -7}
```

含义是：

```text
左边传感器权重大
右边传感器权重为负
越靠边，误差越大
越靠中间，误差越小
```

误差计算公式：

```text
error = Σ(weight[i] × active[i]) / active_count / 7
```

最后得到一个范围大约为：

```text
-1.0 ~ +1.0
```

项目说明中也明确了使用 8 路红外加权求和进行连续位置估计。

---

# 十二、加权法代码示例

```c
float Tracker_CalcError(void)
{
    const int8_t weight[8] = {7, 5, 3, 1, -1, -3, -5, -7};
    uint8_t active[8];
    int16_t sum = 0;
    uint8_t count = 0;
    uint8_t i;

    Tracker_ReadAll(active);

    for(i = 0; i < 8; i++)
    {
        if(active[i])
        {
            sum += weight[i];
            count++;
        }
    }

    if(count == 0)
    {
        // 全白，脱线
        return 0.0f;
    }

    return (float)sum / count / 7.0f;
}
```

# 十三、全白和全黑判断

## 1. 全白

如果没有任何一个传感器检测到黑线：

```text
blackCount == 0
```

说明可能脱线。

处理方式：

```text
停车
按照上一次误差方向找线
低速原地修正
```

你的项目中，全白被视为脱线，会立即刹车并重置 PID。

---

## 2. 全黑

如果 8 个传感器全部检测到黑线：

```text
blackCount >= 8
```

说明可能到达终点线，或者经过黑色标记区域。

处理方式：

```text
停车
切换状态
记录圈数
执行特殊动作
```

你的项目中，全黑被视为终点，也会立即刹车并重置 PID。

# 十四、红外读取和 PID 的关系

红外传感器不是直接控制电机，而是先计算误差：

```text
红外状态 → 黑线位置 → error
```

然后 PID 根据 error 计算转向量：

```text
turn = Kp × error + Kd × (error - lastError)
```

最后控制左右轮 PWM：

```text
left  = basePwm + turn
right = basePwm - turn
```

所以完整流程是：

```text
读取 8 路红外
计算 blackCount
判断全白/全黑
计算 error
PID 计算 turn
左右电机差速输出
```

# 十五、红外读取常见问题

## 1. 读数全是 1 或全是 0

可能原因：

```text
传感器电源没接
GND 没共地
GPIO 模式错误
黑线有效电平判断反了
传感器电位器阈值没调好
```

---

## 2. 小车左右转向反了

可能原因：

```text
传感器左右顺序写反
权重正负写反
左右电机 PWM 公式写反
电机方向接反
```

解决方法：

```text
方法一：交换权重数组正负
方法二：调整 S1~S8 的顺序
方法三：修改 left/right 差速公式
```

---

## 3. 小车在黑线上抖动

可能原因：

```text
传感器太灵敏
黑线边缘检测不稳定
采样周期太短
Kp 太大
Kd 太小
车速太快
```

---

## 4. 小车容易丢线

可能原因：

```text
车速太快
传感器离地太高
黑线太窄
转弯半径太小
basePwm 太大
PID 参数不合适
```

---

## 5. 红外受环境光影响

解决方法：

```text
降低传感器离地高度
避免强光直射
调整模块电位器阈值
给传感器加遮光结构
使用抗干扰更好的传感器阵列
```

---

# 十六、红外读取调试步骤

建议按这个顺序调：

```text
1. 只接一个红外传感器
2. 用串口或 LED 显示读取结果
3. 分别放在白底和黑线上测试
4. 确认黑线到底是 0 还是 1
5. 再接 8 路红外
6. 打印 8 路状态，例如 00111000
7. 检查 S1~S8 顺序是否正确
8. 检查全白和全黑判断
9. 检查 error 是否随着黑线位置平滑变化
10. 最后再接入 PID 和电机控制
```

---

# 十七、推荐串口打印格式

调试时可以打印：

```text
S: 0 0 1 1 0 0 0 0   count=2   error=0.57
S: 0 0 0 1 1 0 0 0   count=2   error=0.00
S: 0 0 0 0 1 1 0 0   count=2   error=-0.57
```

这样你能直接看出：

```text
传感器有没有读对
黑线位置有没有判断对
误差方向是否正确
```

# 十八、红外读取最小掌握版本

只为了先把循迹小车跑起来，重点掌握这些：

```text
1. 红外传感器用来识别黑线和白底
2. 数字输出 DO 只有 0 和 1
3. STM32 用 GPIO 输入读取红外状态
4. 先确认黑线输出 0 还是 1
5. 8 路红外接 PD0~PD7
6. 每一路读到黑线就记为 active=1
7. blackCount=0 表示全白脱线
8. blackCount=8 表示全黑终点
9. 用加权法计算 error
10. error 再交给 PID 控制小车转向
```

一句话总结：

```text
红外读取的核心不是简单读 0 和 1，而是把 8 路黑白状态转换成小车偏离黑线的误差 error。
```
