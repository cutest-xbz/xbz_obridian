## 一、基础电子知识

### 1. 电路基础

需要会：

- 电压、电流、电阻、功率
- 直流电源供电
- GND 共地
- 上拉电阻、下拉电阻
- 短路、反接、过流的危害
- 万用表测电压、测通断

循迹小车里最常见的问题就是：

## 二、单片机基础

你至少要学会 STM32 的这些外设：

### 1. GPIO

用于读取红外传感器、控制电机方向。

需要掌握：

- 输入模式
- 输出模式
- 上拉输入
- 推挽输出
- 高低电平判断
- 引脚初始化

例如你这个小车中，红外 S1~S8 接在 `PD0~PD7`，使用 GPIOD 上拉输入；电机方向控制用 `PD9/PD11`、`PD12/PD10`。

---

### 2. 定时器 TIM

定时器主要用于：

- 产生 PWM
- 周期性任务调度
- 控制小车每隔固定时间执行一次循迹算法

需要掌握：

- 定时器时钟来源
- 预分频 PSC
- 自动重装载 ARR
- 比较值 CCR
- PWM 占空比
- PWM 频率计算

你这个项目里，左电机 PWM 是 `PA6 / TIM3_CH1`，右电机 PWM 是 `PA7 / TIM3_CH2`，PWM 频率为 10kHz。

---

### 3. SysTick

SysTick 用来做 1ms 系统节拍。

需要掌握：

- 1ms 定时中断
- 延时函数
- 周期任务
- 10ms 调度一次循迹控制

你的项目是 `SysTick 1ms → 调度器 → task_10ms() → CarDrive_Run()`，也就是每 10ms 控制一次小车。

### 1. 红外传感器原理

- 模拟输出和数字输出的区别
- 阈值调节
- 光照干扰
- 传感器高度影响识别效果

---

### 2. 多路红外循迹

8 路红外不是简单判断左转右转，而是要计算小车偏离黑线的程度。

需要掌握：

- 每一路传感器的黑白状态
- 传感器从左到右编号
- 黑线在左边、小车应该向左修正
- 黑线在右边、小车应该向右修正
- 全白表示脱线
- 全黑可以表示终点

你这个项目用的是 8 路红外加权法，权重是：

```
{7, 5, 3, 1, -1, -3, -5, -7}
```

通过加权平均计算误差：

```
error = Σ(weight[i] × active[i]) / active_count / 7
```

最后得到一个 `[-1.0, +1.0]` 的连续误差值。

## 六、循迹控制算法

### 1. 最简单的循迹逻辑

入门可以先学这种：

```
中间检测到黑线：直走左边检测到黑线：左转右边检测到黑线：右转全白：停车或按照上一次方向找线全黑：停车
```

这是最简单的逻辑控制。

---

### 2. 差速转向

循迹小车通常是左右轮差速控制：

```
左轮速度 = 基础速度 + 转向量右轮速度 = 基础速度 - 转向量
```

例如：

```
turn > 0：左轮更快，右轮更慢turn < 0：右轮更快，左轮更慢
```

你这个项目就是这种控制方式：

```
left = basePwm + turnright = basePwm - turn
```

并且会限制速度范围。

---

### 3. PID 控制

需要掌握：

- 什么是误差 `error`
- 比例 P
- 积分 I
- 微分 D
- PID 输出如何变成转向量
- 参数怎么调

你这个小车当前用的是位置式 PID：

```
u(k) = Kp × e(k) + Kd × [e(k) - e(k-1)]
```

其中 `Ki = 0`，相当于主要用 PD 控制。

简单理解：

```
Kp：偏得越多，修正越猛Kd：抑制左右摆动Ki：一般循迹小车初期可以不用
```
